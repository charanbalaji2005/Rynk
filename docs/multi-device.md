# Multi-device

Discovering other Rynk computers and listing their apps is built in — see
[discovery.md](discovery.md).

What Rynk deliberately does **not** do is let one computer control another.
Remote management (starting or stopping apps on another laptop) would need
pairing, per-device keys and mutual authentication, and is not part of this
release. Every node's network-facing surface is read-only.
